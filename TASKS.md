## Task coordination

- One human assignee and one branch per task; use
  `<developer>/<issue-number>-<short-description>`.
- Before coding, check the assignee and recent comments, assign yourself if
  unclaimed, and record the branch, files, dependencies, and acceptance criteria.
  Refresh and confirm ownership. Claims are coordination, not an atomic file lock.
- Coordinate overlapping files or interface changes directly with your teammate.
- Update the issue with progress, blockers, and a PR link. Leave a concise handoff
  before switching sessions or handing the task to the other person.
- If GitHub is unavailable, both people must explicitly agree on ownership in
  a shared conversation; copy that agreement to the issue when access returns.

Keep this file for agreed project scope, milestones, and durable decisions.
Change it when those decisions change, rather than for every task status update.
