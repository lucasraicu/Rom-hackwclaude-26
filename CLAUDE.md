# Hackathon

The stack is not chosen. Do not scaffold a full app unless asked.

## Before editing

- Read `TASKS.md` and claim a task (your name and a branch) before editing.
- One branch per task. Open a pull request back to `main`.

## Git

- Never force-push or hard-reset.
- Never commit secrets or `.env` files.

Personal Claude preferences go in gitignored `.claude/settings.local.json`, not in shared files.
