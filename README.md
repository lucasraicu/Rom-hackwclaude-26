# Rom-hackwclaude-26

Two-person hackathon repo for working with Claude in Claude Code and Cursor.

Clone: https://github.com/lucasraicu/Rom-hackwclaude-26.git

## Workflow

1. Claim a task in `TASKS.md` (your name and branch).
2. Use one branch per task.
3. Open a pull request back to `main`.

Shared rules are in `CLAUDE.md`.
